# Features

Mapas progressivos por feature.

## Features mapeadas

- `process-management.md`: CRUD de processos, stages, atividades, bulk, metricas, cron.
- `process-queue.md`: filas BullMQ (insert, validation, solvency, extraction, petition).
- `document-insights.md`: analise de documentos com Vertex AI, prompts.
- `pipedrive-integration.md`: integracao com CRM Pipedrive.
- `auth-users.md`: autenticacao JWT, API Key, usuarios e roles.
- `notifications.md`: notificacoes real-time via WebSocket.

## Quando criar um novo mapa

Crie quando uma task revelar area funcional recorrente sem mapa proprio. Use `_template.md` como base.
